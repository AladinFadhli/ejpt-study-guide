# Tool Reference

What each standard, publicly-documented tool does and when to reach for it. These are the tools taught in INE's PTS path and used across entry-level pentesting.

The point of this folder is **not** to be a command cheat sheet you copy blindly. It's to help you know *which* tool fits *which* task, so the methodology has hands. Learn what each does; look up exact syntax as needed.

- [Reconnaissance](reconnaissance.md) — passive and active information gathering
- [Scanning and enumeration](scanning-enumeration.md) — port scanning and per-service enumeration
- [Exploitation](exploitation.md) — gaining a foothold
- [Post-exploitation](post-exploitation.md) — after access, including privilege escalation
- [Pivoting](pivoting.md) — reaching internal networks
- [Web application](web-application.md) — testing web apps

Every tool here is standard, legal to use on systems you're authorised to test, and part of a normal Kali/Parrot install or a documented add-on. Use them only where you have permission.
